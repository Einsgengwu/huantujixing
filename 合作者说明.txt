《宦途疾行》协作包 — 使用说明
================================

【怎么打开】
1. 解压整个文件夹到任意位置（路径尽量不含特殊字符）
2. 双击 serve.bat
3. 浏览器打开 http://localhost:8765

若未安装 Python：请先安装 Python 3（https://www.python.org），
或在文件夹内打开命令行，执行：
  python -m http.server 8765

注意：不要直接双击 index.html，需通过本地服务器打开，否则数据无法加载。

【怎么玩】
- 点「开跑」开始
- 鼠标/手指跟随移动，碰触拾取道具
- P 键或右上角暂停
- 四线官职均升满 → 碰触落下的黄袍 → 八阵逼宫 → 伪帝战 → 登基结局
